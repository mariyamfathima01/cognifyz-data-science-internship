About the Internship

This repository contains the projects and tasks I completed during my Data Science Internship at Cognifyz Technologies. The work involved data exploration, preprocessing, descriptive analysis, geospatial analysis, price range analysis, and feature engineering using restaurant dataset information.

Level 1 – Data Analysis

Task 1: Data Exploration and Preprocessing

- Identified the number of rows and columns.
- Checked and handled missing values.
- Performed data type conversion where required.
- Analyzed the distribution of Aggregate Rating and class imbalance.

Task 2: Descriptive Analysis

- Calculated mean, median, standard deviation, and other statistical measures.
- Explored categorical variables such as Country Code, City, and Cuisines.
- Identified the most popular cuisines and cities with the highest number of restaurants.

Task 3: Geospatial Analysis

- Visualized restaurant locations using latitude and longitude.
- Analyzed restaurant distribution across cities and countries.
- Examined the correlation between restaurant location and ratings.

Level 2 – Advanced Analysis

Task 1: Table Booking and Online Delivery

- Calculated the percentage of restaurants offering table booking and online delivery.
- Compared average ratings of restaurants with and without table booking.
- Analyzed online delivery availability across price ranges.

Task 2: Price Range Analysis

- Identified the most common restaurant price range.
- Calculated average ratings for each price range.
- Identified the color associated with the highest average rating.

Task 3: Feature Engineering

- Extracted restaurant name length and address length.
- Created Has Table Booking and Has Online Delivery features.
- Encoded categorical variables for analysis.

Key Findings

- New Delhi had the highest number of restaurants in the dataset.
- North Indian was the most popular cuisine.
- Restaurants offering table booking had a higher average rating.
- Price range 4 had the highest average rating.
- Feature engineering created additional variables for analysis.
